## Security Considerations

*   **Master Password:** The security of your notes depends entirely on the strength and secrecy of your master password.  Choose a strong password and never share it with anyone.
*   **Storage:** The encrypted notes are stored in a local file.  Ensure that this file is stored securely and backed up regularly.
*   **Code Auditing:** While efforts have been made to ensure the security of this application, it is always recommended to have the code audited by security professionals.
